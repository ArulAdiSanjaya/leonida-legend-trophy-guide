Roadmap to the Platinum

Seven stages, in the order this guide recommends playing them. Finish each stage's trophies before moving on — Stage 4 exists so the four missables are banked before the final mission.

Missable Trophies

Only four of the 55 trophies meet this guide's strict missable standard: the official description itself implies a one-chance moment. Everything else can be cleaned up in free roam — but note that mission replay for trophies is not confirmed, so this guide still advises doing mission-specific actions on the first pass.

About Leonida Legend

Leonida Legend is an unofficial, offline fan guide. Trophy names, descriptions and grades are the official PS5 list as published; all guide advice is original to this guide. No game artwork or logos are used.
